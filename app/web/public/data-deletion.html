User Data Deletion

Last updated: 25 September 2026

Delete your account

ReelEngine provides an account deletion process for authenticated users. To request deletion, sign in to your ReelEngine account and submit the account deletion request from the User Data Deletion page.

The deletion request requires you to select a reason. You may also provide optional additional feedback.

Sign in to ReelEngine

What happens after you submit?

Once a deletion request is submitted, the account enters a deletion process. New video conversions are disabled while the deletion is being processed.

If a conversion is already running, ReelEngine waits for the active conversion to finish before completing the account deletion.

When deletion is completed, the account's stored download files and associated account records are removed, including authentication identities, sessions, conversion history, and usage records.

The deleted account can no longer be used to sign in.

What will be deleted?

The account deletion process removes the account information and account-associated data stored by ReelEngine, including authentication identities, sessions, conversion history, usage records, and conversion files.

Existing legacy records that are not associated with an individual account are not part of this account-deletion process.

Deletion processing

ReelEngine processes deletion requests asynchronously so that an active conversion can finish safely before the account and its associated files are removed.

If you submit another deletion request while one is already being processed, ReelEngine will continue processing the existing request.
